EDRA Dashboard - Web Publish Package

Goi nay dung de dua ban thuyet trinh HTML len web.

File chinh:
- index.html

Tai san bat buoc:
- assets/edra-logo.png

Cach publish nhanh:
1. Upload ca thu muc web-publish len static hosting.
2. Cac lua chon phu hop:
   - Netlify: drag/drop thu muc vao phan Deploys.
   - Vercel: tao static project va upload/import thu muc.
   - GitHub Pages: push noi dung thu muc nay len repo va bat Pages.

Cach sua sau nay:
- Sua nhanh text/style: sua truc tiep index.html.
- Sua du lieu/layout bai ban: sua file trong source/ roi rebuild lai dashboard tu workspace Codex.
- Sua tren web: bam Edit o goc tren ben phai, sua chu truc tiep, bam vao o anh san pham de them anh.
- Bam Save de luu vao trinh duyet hien tai.
- Bam Download HTML de tai ra file HTML da nhung san chu/anh vua sua. Upload file nay len web de nguoi khac xem dung ban da sua.
- Bam Export de tai file edra-dashboard-edits.json lam ban sao luu.
- Khi doi may/trinh duyet hoac deploy lai, bam Import de nap lai file edra-dashboard-edits.json.

Ghi chu:
- Day la static HTML, khong can backend/server.
- Luon giu thu muc assets nam canh index.html.
- Neu dua len public web, ai co link se xem duoc noi dung.
- Cac anh them bang Edit duoc luu trong trinh duyet; nen Export sau khi them anh.
